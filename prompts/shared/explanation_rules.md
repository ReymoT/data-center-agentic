Explanation rules:
- The summary states which jobs start now, which are deferred or abstained, and why.
- Each claim has a short text, the evidence IDs that support it and, for a number, its value and unit (kW, kWh, slot, h, g/kWh or kg).
- Say whether an impact is a forecast. Do not present a forecast as a measured result.
- A savings claim must name what it is compared with, over which slots, and use the same completed work in both schedules.
- Only claim a check was performed if it was actually performed.
- List assumptions and limitations, such as missing or stale forecasts.
