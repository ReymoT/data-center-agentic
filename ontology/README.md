# Ontology preparation

Owner: Ved. RDF graph construction, controlled retrieval and equivalent flat
projection are implemented in `dc_sustainability/knowledge/graph.py` and
`retrieval.py`. Ontology/SHACL loading, validation and unit-mapping helpers are in
`ontology.py`, with the vocabulary and shapes in this folder. The earlier
preparation-only statement is superseded by those implemented modules.

Keep private episode contents outside policy views and distinguish graph
validation from authoritative F02 checker/controller inputs. See the maintained
[F02 interfaces](../docs/INTERFACES.md) and [architecture](../docs/ARCHITECTURE.md).
These mechanisms do not establish source rights, complete downstream adoption,
held-out study findings or scientific freeze. No substitute schema is introduced.
