# Evaluations

This directory is the top-level index for the project's evaluation materials. It
does not duplicate or move existing code, data or evidence.

- Evaluation code: [`dc_sustainability/evaluation/`](../dc_sustainability/evaluation/)
- Human faithfulness rules and development records: [`docs/e04/`](../docs/e04/)
- Generated result location and conventions: [`results/`](../results/)
- Experiment runner and registry: [`dc_sustainability/experiments/`](../dc_sustainability/experiments/)

Only public development artifacts and sanitized evidence may be committed. Held-out
keys, restricted inputs, credentials, private ratings and raw local runtime records
remain outside the repository unless their release is separately authorized.
